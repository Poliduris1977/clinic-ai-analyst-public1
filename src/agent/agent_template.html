ИИ-агент директора

Демонстрационная модель сети клиник, данные 2025 года (синтетика). Числа берутся только из функций доступа к данным, совпадающих с логикой книг Excel.

Это не языковая модель: агент распознаёт вопрос, вызывает функции и собирает ответ по шаблону с проверкой каждого числа. Вопросы вне набора получают явный ответ «в данных нет».
