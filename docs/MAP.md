Строки в якорях приблизительные (дрейфуют после правок): ищи через `grep -n "^def \|# ----" файл`.

## Структура
```
clinic-analyst/
  data/  raw (эталон) | dirty (с ошибками) | corrected (вход отчётов) | output (находки, журнал) |
         output_corrected (повторная сверка) | reports (4 книги) | answer_key (НЕ показывать агенту)
  src/common/    ledger.py (закрытие, ОСВ, ДДС), recalc.py (пересчёт xlsx в LibreOffice)
  src/generate/  generate_reference | generate_operations | generate_1c | generate_budget | inject_errors
  src/dashboard/ build_dashboard.py (чтение книг data/reports и output_v2, проверки п. 29, сборка Dashboard_2025.html; блоки cash, doc, pat, стресс) | dashboard_template.html (семь вкладок, SVG-графики; stressCalc, renderStress)
  sql/ 01-09 *.sql (запросы SQLite) + README.md | src/sql/build_db.py (CSV -> data/sql/*.db) | src/sql/run_sql.py (31 SQL-контроль)
  docs/REGLAMENT.md (регламент закрытия месяца)
  src/reconcile/ reconcile.py | apply_corrections.py
  src/reports/   build_pnl.py | build_planfact.py | build_factor.py | build_doctors.py
  src/agent/     tools.py (6 функций доступа к данным) | build_agent.py (паспорта, verify, HTML) | agent_template.html (JS-маршрутизатор, журнал) | test_agent.py (35 проверок)
  docs/          ONE_PAGER, PROJECT, REGLAMENT, ASSUMPTIONS, BLIND_RESULT, BLIND_SCHEMA, MAP
```
Скрипты запускаются из корня. `build_planfact` импортирует `build_pnl` (факт), `build_factor` импортирует `build_planfact` (`prepare` для плана и факта затрат). Отчётные скрипты добавляют `src/` в `sys.path` для `common.recalc`.

## Конвенции книг
Синий шрифт вход, зелёный ссылка на другой лист, чёрный расчёт, жёлтая заливка фильтр. Фильтры: `B2` клиника, `B3` направление, рядом `C2`, `C3` = `IF(B="Все","*",B)` для SUMIFS. Формат `#,##0,` показывает тысячи из рублей. В факторных книгах плюс = выгодно для маржи. Книги сохраняются openpyxl, затем `recalculate(path)`.

## Подводные камни среды
- Контейнер между окнами не сохраняется; `data/` восстанавливается прогоном цепочки.
- CSV в `utf-8-sig`. Счета в проводках (`debit`, `credit`, `account`) читать как `dtype=str`, иначе «62.01» превращается в число.
- В `sh` не работает `mkdir -p a/{b,c}` (создавать папки по одной); `/usr/bin/time` отсутствует; `cut -c` ломает вывод с кириллицей (использовать python).
- openpyxl пишет формулы без значений: после сохранения вызывать `recalculate` (LibreOffice `soffice --headless --convert-to xlsx`). Версии, на которых всё проверено: pandas 3.0.2, numpy 2.4.4, openpyxl 3.1.5.
- Приложенные файлы попадают в контекст целиком: тяжёлое прикладывать архивом.
